Setup guide

1. Download Health Auto Export from the App Store
2. Go to Automations → Google Drive (Premium) to auto-push nightly
3. Select data types: Sleep, HRV, Resting HR, Workouts
4. Set format to JSON, schedule Daily at 6am
5. Each morning open Drive, download the file, import here
